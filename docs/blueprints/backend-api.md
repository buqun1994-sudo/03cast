# backend-api

## 1. 适用

1. API 服务。
2. Worker。
3. Server。
4. 数据服务。

## 2. 默认目录

1. `src/`：服务入口、路由、用例、领域和适配器。
2. `tests/`：单元和集成测试。
3. `docs/api/`：接口契约。

## 3. 必补事实

1. 运行时。
2. API 风格。
3. 数据存储。
4. 鉴权方式。
5. 环境变量边界。
6. 部署和回滚入口。

## 4. 验证

1. 类型或语法检查。
2. 单元测试。
3. 接口契约测试。
4. dry-run 或本地集成测试。

## 5. 禁止

1. 不信任客户端传入的权限、金额、归属或数据状态。
2. 不在无迁移方案时修改持久化 schema。

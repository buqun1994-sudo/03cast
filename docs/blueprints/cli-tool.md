# cli-tool

## 1. 适用

1. 命令行工具。
2. 自动化脚本。
3. 本地批处理工具。

## 2. 默认目录

1. `src/`：命令入口和核心逻辑。
2. `tests/`：命令行为和边界测试。
3. `docs/usage/`：使用说明和示例。

## 3. 必补事实

1. 命令名。
2. 输入输出格式。
3. dry-run 语义。
4. 幂等规则。
5. 错误码。

## 4. 验证

1. 语法检查。
2. 命令 dry-run。
3. fixture 输入输出对比。

## 5. 禁止

1. 不默认执行破坏性操作。
2. 不在没有 `--dry-run` 或确认参数时删除、覆盖或迁移真实数据。

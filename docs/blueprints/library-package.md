# library-package

## 1. 适用

1. SDK。
2. 组件库。
3. 协议包。
4. 可复用工具包。

## 2. 默认目录

1. `src/`：公共 API 和内部实现。
2. `tests/`：公共契约和边界测试。
3. `docs/api/`：API 说明。

## 3. 必补事实

1. 包名。
2. 公共 API。
3. 版本策略。
4. 兼容策略。
5. 发布策略。

## 4. 验证

1. 类型或语法检查。
2. 单元测试。
3. 打包检查。
4. API 契约检查。

## 5. 禁止

1. 不在未记录兼容策略时破坏公共 API。
2. 不把内部实现暴露成长期公共接口。

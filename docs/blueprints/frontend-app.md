# frontend-app

## 1. 适用

1. 浏览器前端。
2. Web App。
3. 管理台。
4. 数据可视化工具。

## 2. 默认目录

1. `src/`：页面、组件、状态、接口适配。
2. `public/`：静态资源。
3. `tests/`：单元、组件或端到端测试。

## 3. 必补事实

1. 前端框架。
2. 包管理器。
3. 路由方式。
4. 设计系统。
5. API 来源。
6. 运行级 smoke 入口。
7. 界面语言、fallback locale、JSON 词典目录和 localization provider / hook。

## 4. 验证

1. 类型检查。
2. lint。
3. 构建。
4. 关键页面 smoke。
5. locale JSON key parity 与至少两种语言的关键页面 smoke。

## 5. 禁止

1. 不把 mock 数据当作真实后端能力。
2. 不把设计占位当作最终视觉系统。

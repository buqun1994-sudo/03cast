# website

## 1. 适用

1. 官网。
2. 文档站。
3. 营销页。
4. 内容站。

## 2. 默认目录

1. `src/`：页面、组件和内容渲染。
2. `public/`：静态资源。
3. `content/`：结构化内容，按技术栈决定是否启用。

## 3. 必补事实

1. 站点目标。
2. 内容来源。
3. 视觉基线。
4. 发布入口。
5. SEO 和可访问性要求。
6. 视觉或交互 smoke 入口。
7. 站点 locale、fallback、语言路由 / 检测和结构化文案来源。

## 4. 验证

1. 构建。
2. 链接检查。
3. 关键页面 smoke。
4. 文案和视觉抽查。
5. locale JSON key parity、跨语言链接与至少两种语言的关键页面 smoke。

## 5. 禁止

1. 不把营销页面当作产品功能已完成证据。
2. 不在未授权时部署或上线。

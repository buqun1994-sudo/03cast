# desktop-client

## 1. 适用

1. 桌面客户端。
2. 本地 GUI。
3. 本地工具。

## 2. 默认目录

1. `src/`：应用入口、UI、领域逻辑、本地适配器。
2. `assets/`：应用资源。
3. `tests/`：单元、集成和关键交互测试。

## 3. 必补事实

1. 桌面框架。
2. 目标平台。
3. 本地数据目录。
4. 配置和日志边界。
5. 打包方式。
6. 运行级 smoke 入口。
7. 系统语言解析、fallback locale、JSON / 平台资源目录和运行时语言服务。

## 4. 验证

1. 编译或类型检查。
2. 单元测试。
3. 启动 smoke。
4. 关键交互 smoke。
5. locale 资源 key parity 与至少两种语言的启动 smoke。

## 5. 禁止

1. 不把本地调试路径写成长期配置。
2. 不在 UI 层复制领域规则。

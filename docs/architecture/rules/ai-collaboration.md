# AI 协作规则

## 1. 默认规则

1. AI 必须先读取根 `AGENTS.md` 和命中任务的路由文档。
2. 低风险缺字段任务可以合理假设并推进，高风险任务缺范围、完成标准或人工门禁时必须追问。
3. 发现同类问题第二次出现时，不只修当前问题，还要沉淀规则、测试、skill 或 hook。
4. 收尾必须说明实际验证和剩余最小人工确认。
5. 不把一次会话的临时判断提升为长期架构结论。
6. 发现适合所有新项目默认具备的能力、skill、规则、检查或文档槽位时，必须记录为候选通用能力；确认跨项目通用后通过 `template-feedback` 回流到本地模板源 `/Users/q/Documents/Projects/NewProject`，不能让复制后的项目把自己当作模板源。
7. 当前工作区无法访问本地模板源时，交付说明必须标记“待回流本地模板源”，并写清候选内容、证据、去专有化要求和建议落点。
8. 创建或更新项目级 skill 时必须使用 `skill-authoring`，并同步能力池、验证矩阵和进度记录。

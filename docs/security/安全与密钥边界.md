# 安全与密钥边界

## 1. 禁止提交

1. 真实密钥、token、私钥、证书、生产配置。
2. `.env`、`.env.*.local`、`*.local.*`、本地数据库、缓存和部署日志。
3. 包含敏感信息的截图、录屏、调试日志、错误报告和测试 fixture。

## 2. 必须区分

1. 客户端可公开配置。
2. 服务端环境变量。
3. 只能由部署平台或密钥系统注入的机密。
4. 生产数据、测试数据和本地 fixture。

## 3. 客户端公开环境配置

1. 用户协议页面是公开地址，不属于密钥：Debug 固定使用 `https://staging.9studio.fun/icar03/terms`，Release 固定使用 `https://9.9studio.fun/icar03/terms`。
2. 两个地址通过 Android 构建类型写入 `BuildConfig`，由客户端离线生成二维码；版本号不参与环境判断，运行时不向云服务请求二维码地址。
3. 后续如页面迁移，优先由上述稳定地址做 `301 / 302` 跳转；只有同一包确需动态切换环境时才引入带本地默认值和签名校验的配置下发。

## 4. Android 权限与车机授权边界

1. `INTERNET`、`ACCESS_NETWORK_STATE`、`ACCESS_WIFI_STATE`、`CHANGE_WIFI_MULTICAST_STATE` 和 `WAKE_LOCK` 仅用于局域网接收、组播发现和保持播放，不弹出用户运行时授权框，由系统自动授予。
2. `android.car.permission.CAR_POWERTRAIN` 仅用于只读车辆档位；它由车机系统 / 签名权限控制，不是应用内可自行申请的用户授权。包名迁移前的旧包 `com.tcrrry.desktopcast` 曾在 `S56_HQX` 验证为 `granted=true`；新包 `com.ninepointnine.desktopcast` 尚未完成该车机权限复验，属于迁移后的剩余真机门禁。若未授予，应用只显示“暂时无法读取车辆状态”，不会写入车辆状态。
3. 本应用不声明 `SYSTEM_ALERT_WINDOW`、无障碍服务、通知监听、前台服务、蓝牙、存储、安装包、开机广播或用户数据权限；控制层使用 attached `PopupWindow`，标准浮窗和全屏歌词避让使用公开车机窗口事件 / 租约协议，不需要用户到系统设置手动开启授权。
4. 当前 Debug 车机安装只使用 `adb install -r -g` 作为开发覆盖安装手段，不属于产品运行时授权，也不代表正式发布权限。

## 5. 设备商业与签名边界

1. 03投屏与 03歌词使用不同的 `productId`、SKU、Android 包名、应用签名摘要、设备指纹上下文、设备公钥和本地许可证存储记录；任何一项不匹配都必须拒绝准入。
2. 客户端只持有对应环境的许可证公钥和 `keyId`；许可证私钥、活动密文、订单凭据和服务端 HMAC / AES 材料只存在 cloud 或部署密钥系统，不进入 Android 仓库。
3. Debug fixture 的许可证签名器在 Android Keystore 运行时生成 `03cast` 专用 P-256 密钥，不把私钥或可复用的正式许可证写入源码；Release / staging trust bundle 或签名材料缺失时必须 fail closed。
4. 客户端不固化 `¥65.00`、`¥39.00`、活动码、折扣比例或订单金额；这些值只作为 cloud / Debug fixture 的测试断言，生产支付请求必须携带服务端返回的 quote 引用和最终金额。
5. 关于页二维码地址是公开配置，不是密钥；Debug / Release 地址由构建类型注入，离线生成二维码，不从网络动态下发。
6. 本轮在仓库外生成了独立的 staging / production APK 签名材料并完成本地签名校验；这些材料只用于身份迁移和构建验证，尚未注入 cloud trust bundle。仍不执行真实支付、退款、生产部署或云端 secret 轮换。

## 6. 人工门禁

以下动作必须先取得用户明确确认：

1. 生产部署或正式上线。
2. 修改权限、密钥、支付、账号、用户数据或数据库迁移。
3. 删除数据、重置环境、吊销凭证或执行不可逆操作。

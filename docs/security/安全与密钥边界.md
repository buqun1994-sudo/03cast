# 安全与密钥边界

## 1. 禁止提交

1. 真实密钥、token、私钥、证书、生产配置。
2. `.env`、`.env.*.local`、`*.local.*`、本地数据库、缓存和部署日志。
3. 包含敏感信息的截图、录屏、调试日志、错误报告和测试 fixture。

## 2. 必须区分

1. 客户端可公开配置。
2. 服务端环境变量。
3. 只能由部署平台或密钥系统注入的机密。
4. 生产数据、测试数据和本地 fixture。

## 3. 人工门禁

以下动作必须先取得用户明确确认：

1. 生产部署或正式上线。
2. 修改权限、密钥、支付、账号、用户数据或数据库迁移。
3. 删除数据、重置环境、吊销凭证或执行不可逆操作。

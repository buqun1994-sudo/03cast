# 产品需求基线

## 1. 产品定位

1. 产品名称：03投屏
2. 一句话定位：Android 9 iCAR 车机上以最简界面稳定接收 DLNA 与 AirPlay 的独立投屏器
3. 目标用户：在 iCAR 03 车内，希望把手机或电脑中的视频、音频、图片或非 DRM 屏幕画面直接显示到车机的车主与乘员。
4. 非目标用户：需要家庭多房间音响、媒体资源聚合、内容下载、车辆控制或 DRM 绕过能力的用户。
5. 核心问题：原车 DLNA 服务虽能被发现，但控制地址不可访问、格式声明过窄且状态错误；系统没有可用的 AirPlay 接收器。用户需要一个打开即可被发现、连接后直接播放的稳定替代品。

## 2. 核心路径

1. 用户第一条成功路径：从“03桌面”启动“03投屏” -> 标准右侧浮窗显示“等待投屏” -> 应用同时公开 DLNA 与 AirPlay 设备名“03投屏” -> 手机选择该设备 -> 车机自动进入媒体播放或屏幕镜像 -> 用户可切入全屏并回到原浮窗 -> 发送端断开后自动回到等待页 -> 用户关闭窗口后停止接收。
2. V1 成功标准：
   - Android / 网盘类发送端能够发现并连接 DLNA 接收器，常见 MP4、H.264、H.265、AAC、MP3、图片与 HLS 媒体能够交给车机播放器处理。
   - iPhone、iPad 或 Mac 能够发现 AirPlay 接收器并完成非 DRM 屏幕镜像和音频播放。
   - 两种协议同时在线，用户无需在车机选择模式；任一时刻只保留一条活动会话。
   - 播放、暂停、进度、停止与发送端断开能够驱动车机状态正确变化；协议不支持的控制不显示为可用按钮。
   - 网络短暂变化后自动重新公开服务；不可恢复错误给出一句结果和一个重试动作，不暴露协议或调试信息。
   - 界面运行在目标车机标准右侧浮窗中，深浅模式、窗口动效、字号、间距和触控尺寸符合既有 iCAR 规范。
   - 活动媒体可从标准右侧浮窗切换到全屏，并能返回同一浮窗位置；切换不重启接收器、不丢失当前播放会话；全屏可见期间，已安装且支持公开租约的歌词层不会覆盖视频。
3. 明确不做范围：媒体目录与文件浏览、内容聚合、账号、连接历史、专业参数设置、Miracast、Google Cast、AirPlay 多房间、DRM 内容解密、车辆控制、开机自启、退出后后台常驻和手机 / 平板界面适配。

## 3. 验收口径

1. 用户可观察到的完成现象：打开后无需设置即可在 Android 投屏列表和 Apple 屏幕镜像 / 音频列表中看到“03投屏”；连接后画面或声音进入车机；断开后恢复“等待投屏”；关闭应用后设备不再广播。
2. 必须自动验证的部分：领域状态机、单会话互斥、网络重绑、DLNA 描述与控制响应、媒体命令映射、窗口交接令牌、全屏独占租约、构建、Debug 覆盖安装、进程启动和协议端口探测。
3. 剩余最小人工验收：用户分别从真实 DLNA 发送端和 Apple 设备发起一次投屏，确认发现速度、首帧、声画、控制、断开恢复与标准浮窗视觉；受保护视频只验证能明确失败，不要求绕过 DRM。

# 产品需求基线

## 1. 产品定位

1. 产品名称：03投屏
2. 一句话定位：Android 9 iCAR 车机上以最简界面稳定接收 DLNA 与 AirPlay 的独立投屏器
3. 目标用户：在 iCAR 03 车内，希望把手机或电脑中的视频、音频、图片或非 DRM 屏幕画面直接显示到车机的车主与乘员。
4. 非目标用户：需要家庭多房间音响、媒体资源聚合、内容下载、车辆控制或 DRM 绕过能力的用户。
5. 核心问题：原车 DLNA 服务虽能被发现，但控制地址不可访问、格式声明过窄且状态错误；系统没有可用的 AirPlay 接收器。用户需要一个打开标准投屏窗口即可被发现、连接后直接播放的稳定替代品。

## 2. 核心路径

1. 用户第一条成功路径：从“03桌面”启动“03投屏” -> 标准右侧浮窗显示“图标 / 03投屏 / 等待投屏” -> 应用同时公开 DLNA 与 AirPlay 设备名“03投屏” -> 手机选择该设备 -> 车机自动进入媒体播放或屏幕镜像 -> 用户可切入全屏并回到原浮窗 -> 播放中点关闭只断开当前发送端并回到等待页 -> 发送端断开后立即回到等待页且保持当前窗口模式 -> 全屏等待态由用户点击“退出全屏”回到标准浮窗 -> 用户下滑关闭浮窗后停止接收。
2. V1 成功标准：
   - Android / 网盘类发送端能够发现并连接 DLNA 接收器，常见 MP4、H.264、H.265、AAC、MP3、图片与 HLS 媒体能够交给车机播放器处理。
   - iPhone、iPad 或 Mac 能够发现 AirPlay 接收器并完成非 DRM 屏幕镜像和音频播放。
   - 两种协议同时在线，用户无需在车机选择模式；任一时刻只保留一条活动会话。
   - 播放、暂停、进度、停止与发送端断开能够驱动车机状态正确变化；协议不支持的控制不显示为可用按钮。
   - 网络短暂变化后自动重新公开服务；不可恢复错误给出一句结果和一个重试动作，不暴露协议或调试信息。
   - 界面运行在目标车机标准右侧浮窗中，深浅模式、窗口动效、字号、间距和触控尺寸符合既有 iCAR 规范。
   - 活动媒体可从标准右侧浮窗切换到全屏，并能返回同一浮窗位置；切换不重启接收器、不丢失当前播放会话；全屏可见期间，已安装且支持公开租约的歌词层不会覆盖视频。
   - 等待页可进入与 03歌词同构的双栏设置页；行车保护默认开启，读取标准 `CURRENT_GEAR`，只在明确非 P 档时终止活动输出并显示车机内安全倒计时。
   - 标准浮窗通过清单元数据被车机窗口事件识别；启动编排在打开本窗口前清理已有标准浮窗，避免两个标准浮窗重叠。
3. 明确不做范围：媒体目录与文件浏览、内容聚合、账号、连接历史、专业参数设置、Miracast、Google Cast、AirPlay 多房间、DRM 内容解密、车辆控制、开机自启、退出后后台常驻和手机 / 平板界面适配。手机在应用关闭时直接投屏并唤起车机窗口，需要另行设计后台接收与系统启动权限，不属于本轮。

## 3. 验收口径

1. 用户可观察到的完成现象：标准投屏窗口打开后无需额外设置即可在 Android 投屏列表和 Apple 屏幕镜像 / 音频列表中看到“03投屏”；连接后画面或声音进入车机；播放中关闭回到等待页且广播继续；下滑关闭窗口后设备不再广播。
2. 工程自动验证的部分：按本轮影响范围执行领域状态机、单会话互斥、网络重绑、DLNA 描述与控制响应、媒体命令映射、窗口交接令牌、全屏独占租约、构建和直接相关单测；Debug APK 覆盖安装只作为可选交付准备，不把启动或端口状态写成交互通过。
3. 用户手测验收：用户分别从真实 DLNA 发送端和 Apple 设备发起一次投屏，确认发现速度、首帧、声画、控制、断开恢复与标准浮窗视觉；受保护视频只验证能明确失败，不要求绕过 DRM。完整步骤见 `docs/testing/验证矩阵.md`。

## 4. 本轮界面与安全决策

1. 等待态只保留设备图标、设备名、等待状态和设置入口，不显示关闭按钮；标准浮窗的系统下滑手势负责关闭窗口。
2. 活动态顶部显示结束投屏按钮。该按钮与底部播放、底部时间轴作为一个控制层随画面轻触同时出现、静置约 3 秒同时隐藏；播放、全屏和结束投屏触控框统一为 `112 x 112dp`。按钮语义是断开发送端、释放当前媒体并回到等待态；用户主动在全屏活动态点击该按钮后回到标准浮窗，发送端远程断开则保持当前窗口模式并立即进入等待态。全屏等待态提供“退出全屏”按钮；媒体换片产生的短暂 Stop / 重连不得触发窗口交接。
3. “行车时禁止播放”默认开启。关闭开关前必须在应用内完成高风险确认；确认页不是 Android 系统 Dialog。档位明确为非 P 时必须立即建立播放锁、释放视频 / 音频 / 镜像 / 图片输出，先让背景变为纯黑，再显示“为了您的安全，行车状态下禁止播放”和 5 秒退出倒计时，结束后关闭本应用全部任务。
4. 车辆档位不可读时仅显示状态不可用，不伪造 P 档；本轮不以未知状态强行操作车辆或系统窗口。
5. 风险确认页二维码由构建配置决定：Debug 使用测试协议页，Release 使用正式协议页；二维码离线生成，扫码时才访问网络。
